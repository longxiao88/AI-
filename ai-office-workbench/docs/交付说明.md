# 交付说明

AI 办公助手是一个在本机运行的个人办公工作台：写作、会议纪要、项目管理、文档分析、资源库、知识库、全局搜索和 AI 问答放在同一个界面里，数据保存在本机 SQLite，AI 功能通过 OpenAI 兼容接口连接你自己选择的模型服务。

当前版本 **0.4.3**（2026-10-30），改动记录见 `docs/更新说明.md`。

## 2. 运行环境

- Windows 10/11 或 macOS，Node.js 22.5 或更高版本（推荐 24 LTS；用 22.x 时会自动带 `--experimental-sqlite` 启动）。
- 新版 Chrome、Edge 或 Safari。主题揭幕动效需要 Chrome / Edge 111+ 或 Safari 18+，更旧的浏览器会自动退化为瞬时切换。
- 第一次安装依赖需要联网；使用云端模型服务时需要能访问该服务。
- 不需要单独安装数据库或其他服务。

## 3. 启动与停止

```sh
npm ci          # 第一次或更新版本后执行
npm run build   # 第一次或修改前端代码后执行
npm start       # 启动，浏览器打开 http://127.0.0.1:4318
```

停止：在运行 `npm start` 的终端按 Ctrl+C。每次启动后需要在「设置」页重新填写 API Key（密钥只存进程内存，不落盘）。详细步骤、邮件配置、换端口、备份恢复、升级和常见问题见 `docs/安装与使用.md`。

## 4. 功能范围

**账号与数据**

- 多账号存储与切换：同一工作空间可注册多个账号，注册后在登录页点一下即可切换。
- 各账号的写作、会议、项目、文档、知识库、资源、任务看板与操作日志**完全隔离**，隔离在服务端完成。
- 账号找回：绑定邮箱后可通过邮箱验证码自助重置密码（验证码 5 分钟有效、最多试 5 次、哈希存储）。
- 邮箱绑定：需先通过验证码验证；一个邮箱只能绑定一个账号。
- 操作日志：记录每次增改删的前后内容，可回溯撤销，日志同样按账号隔离。

**内容与 AI**

- 写作、会议、项目（含任务看板）、文档、知识库、资源六类记录的新增、修改、删除，真实保存在本机数据库。
- **八个 AI 入口**：写作（撰写 / 润色 / 摘要）、会议摘要与待办、项目任务拆解、文档分析、**工程导图**、基于知识库资料的问答（标注来源）、独立多轮问答、资源文件快速分析。AI 结果先作为草稿，确认后才保存。
- **全局搜索**：一个入口跨五个模块检索全部记录，显示命中片段，点击跳到对应记录。
- **资源库**：上传 Word / Excel / PDF / 文本 / 图片与 `.zip` 压缩包；Word 转 HTML 预览、Excel 转表格预览；`.zip` 自动解压成多条资源且**保留原件**（解压上限 50 个文件 / 200 MB，单文件上传上限 50 MB）。
- **模块间内容流动**：知识库与文档分析从资源库取正文；会议待办可一键转为项目任务；写作结果与问答对话可存入知识库。这些操作都只填充/勾选，不会自动入库。
- **工程导图**：把文档原文提炼成树状结构，支持导出 PNG / SVG / Markdown 大纲。

**界面**

- 日夜主题切换（新主题自底部向上揭幕的过渡）、场景轮播（擦除翻页、可拖动切换）、背景气泡（可点击点破、分裂并溅出水雾）、鱼群背景（五色鱼群，鼠标就近牵引一群、可游出画面）、卡片流光、动效总开关。
- 个人资料、时钟与专注计时。
- 演示版：`npm run build:preview` 生成纯静态页面，只展示界面，不调用 AI、不连接后端、不支持邮件。

**安全设计**

- AI 的 API Key 只存服务进程内存，不落盘，重启即清空；接口从不回传明文。
- SMTP 授权码支持两种方式：环境变量（完全不落库），或 AES-256-GCM 加密后入库（密钥单独存于 `data/.mail-key`）。接口任何情况下都不返回授权码本身。
- 发信防滥用：验证码 60 秒冷却 + 每小时配额。
- 服务只监听 `127.0.0.1` 并校验 Host 白名单；反账号枚举：请求找回验证码时，无论账号是否存在都返回相同提示。

不在本次范围：多人协作与权限分级（多账号仅解决同机多用户的数据隔离）、公网部署、支付会员、PDF 正文解析（仅支持下载）、录音转写、向量检索、问答历史永久保存。具体限制见 `docs/验收清单.md` 末尾。
