# 安装与使用

## 1. 准备环境

- Node.js 24 或更高版本（推荐 24 LTS），从 https://nodejs.org 下载安装。装好后打开终端（Windows 用 PowerShell 或命令提示符，macOS 用「终端」）执行 `node -v`，显示 `v24.x.x` 或更高即可。
- 浏览器：Chrome、Edge 或 Safari 的新版本。
- 只有运行端到端测试（`npm run test:e2e`）时才需要安装 Google Chrome，日常使用不需要。
- 不需要安装数据库，数据用 Node.js 自带的 SQLite 保存在本机。

## 2. 首次安装与启动

把压缩包解压到一个路径里没有特殊符号的目录，终端进入解压后的 `ai-office-workbench` 目录，依次执行：

```sh
npm ci
npm run build
npm start
```

- `npm ci` 按锁文件安装依赖，需要联网，只在第一次或更新版本后执行。较新的 npm 可能提示 install-scripts 相关警告，不影响使用。
- `npm run build` 生成前端页面到 `dist/`，修改前端代码后需要重新执行。
- 看到 `AI 办公助手已启动：http://127.0.0.1:4318` 后，用浏览器打开这个地址。
- 停止服务：在运行 `npm start` 的终端按 Ctrl+C（Windows 如出现「终止批处理操作吗」输入 Y 回车）。

第一次打开会进入「创建账号」：账号为 3–40 位字母、数字或 `._-`，密码至少 8 位。这是本机唯一的账号，请记住密码。

服务只监听 127.0.0.1，同一局域网的其他电脑和手机无法访问。

## 3. 配置 AI 模型

进入「设置」页填写三项，点「保存并测试连接」，看到「连接成功」即可使用 AI 功能：

| 项目 | 说明 |
| --- | --- |
| API 地址 | 服务商提供的 OpenAI 兼容接口基础地址，通常以 `/v1` 结尾，不要带 `/chat/completions`。必须是 https；本机模型服务可用 http，例如 Ollama 为 `http://127.0.0.1:11434/v1` |
| 模型名称 | 服务商文档中的模型 ID，大小写要一致 |
| API Key | 服务商后台申请的密钥。本机 Ollama 不校验密钥，随便填一串字符即可 |

- API Key 只保存在服务进程的内存里，不写数据库、日志或浏览器。**每次重启服务后需要重新填写 Key**，API 地址和模型名称会保留。
- 测试连接会发送一条很短的请求，可能产生少量费用。
- 截图或录屏时注意不要拍到 Key。
- 没有配置 AI 时，所有记录的新增、修改、删除、搜索都照常可用。

## 4. 各模块怎么用

| 模块 | 手动功能 | AI 功能 |
| --- | --- | --- |
| AI 写作 | 标题、要求、结果可编辑保存 | 撰写 / 润色 / 摘要；结果可编辑、复制、导出 TXT |
| 会议纪要 | 日期、原文、结论、待办 | 由原文生成「重点与结论 + 待办」草稿，编辑后应用，再点保存 |
| 项目管理 | 项目说明、任务增删改、三种状态 | 先保存项目，再生成任务草稿；勾选、改名后批量加入 |
| 文档分析 | 导入 UTF-8 的 TXT / Markdown（≤200 KB），写分析笔记 | 生成概述 / 要点 / 建议行动草稿，应用到笔记后保存 |
| 知识库 | 资料、标签、关键词检索 | 用命中的资料整理答案并标注来源；没有命中不调用 AI |
| AI 问答 | — | 多轮追问，最多 20 轮；可复制、导出 TXT |
| 操作日志 | 查看每次增改删的前后内容，可回溯撤销 | — |
| 其他 | 个人资料、时钟与专注计时、日夜主题、动效开关 | — |

使用规则：

- AI 结果都是草稿，应用后还要点「保存」才写入；保存前可以随意修改。请人工核对日期、金额、电话等细节。
- 同一时间只处理一个 AI 请求，等待超过 60 秒会提示超时；失败时输入和已有内容都会保留，不会自动重试。
- AI 原文每次最多 20,000 字，超出会提示缩短，不会自动截断。
- AI 问答的内容只在当前页面，不保存到数据库；离开或刷新前请复制或导出。它不会读取知识库，需要基于资料回答请用知识库页面。
- 有未保存的修改时，切换页面会先确认。

演示用的案例输入见 `docs/演示案例.md`。

## 5. 数据、备份与恢复

- 数据库文件：`data/workbench.sqlite`，第一次启动时自动创建。
- 备份：先按 Ctrl+C 停止服务，再把整个 `data` 文件夹复制到别处（可在文件夹名里加日期）。不要在服务运行时复制。
- 恢复：停止服务，删除或改名当前 `data` 文件夹，把备份的 `data` 文件夹复制回原位置，再 `npm start`。
- 数据库只保存 API 地址和模型名称，不含 API Key，可以放心备份。

## 6. 升级到新版本（保留数据）

1. 停止旧版服务，按上一节备份 `data` 文件夹，旧目录先不要删。
2. 把新版压缩包解压到一个新目录。
3. 把旧目录的 `data` 文件夹复制到新目录里（与 `package.json` 同级）。
4. 在新目录执行 `npm ci`、`npm run build`、`npm start`，用原账号登录，在设置页重新填写 API Key。
5. 确认数据都在以后再删除旧目录；有问题可以回到旧目录继续使用。

## 7. 更换端口或数据库位置

默认端口 4318。被占用时启动会提示「端口 4318 已被占用」，可以先关掉已在运行的那个窗口，或换一个端口：

```sh
# macOS / Linux
PORT=4319 npm start
# Windows PowerShell
$env:PORT=4319; npm start
# Windows 命令提示符（两行分别执行）
set PORT=4319
npm start
```

数据库位置可用 `DB_PATH` 指定（写绝对路径），用法同上。项目不会自动读取 `.env` 文件，`.env.example` 只是说明。

## 8. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| `node` 或 `npm` 不是内部或外部命令 | 没装 Node.js，或装完没重新打开终端 |
| 提示「需要 Node.js 24 或更高版本」 | 升级 Node.js 到 24 LTS，重新打开终端后再执行一次 `npm ci` |
| `npm ci` 很慢或失败 | 检查网络；公司/校园网可换网络或配置 npm 镜像后重试 |
| 提示「端口 4318 已被占用」 | 已有一个服务在运行（可能是旧版本），关掉它或换端口（见第 7 节） |
| 提示「未找到前端页面 dist/」，浏览器显示 Cannot GET / | 先执行 `npm run build` 再 `npm start` |
| 浏览器打不开页面 | 确认终端里服务还在运行，地址是 http://127.0.0.1:4318 |
| 「请先在设置中填写 API Key」 | 重启服务后 Key 会清空，在设置页重新填写 |
| 「API Key 无效或已过期」 | Key 填错、过期或复制时多了空格 |
| 「模型或 API 地址不可用」 | API 地址或模型名称写错；地址不要带 `/chat/completions` |
| 「调用额度不足或请求过于频繁」 | 服务商账户余额或频率限制，去服务商后台查看 |
| 「AI 响应超时」 | 模型较慢或网络不好，缩短输入后手动重试 |
| 「AI 返回的内容不符合约定格式」 | 会议 / 项目 / 文档要求模型返回 JSON，个别模型偶尔不按格式回答，重试一次或换一个模型 |
| 「API 地址需使用 HTTPS」 | 只有本机地址（127.0.0.1 / localhost）允许 http |
| 导入文档提示不是有效的 UTF-8 | 用记事本「另存为」选择 UTF-8 编码后再导入 |
| 连续输错密码被锁定 | 连续失败 10 次锁定 15 分钟，等待后再试 |

忘记密码：系统不提供找回。可以停止服务、先备份 `data`，在项目目录执行下面的命令清除账号（记录全部保留），再启动时重新创建账号：

```sh
node -e "const {DatabaseSync}=require('node:sqlite');const db=new DatabaseSync('data/workbench.sqlite');db.exec('DELETE FROM account; DELETE FROM sessions;');db.close();"
```

## 9. 开发与测试（可选）

- `npm run dev`：开发模式，前端 http://127.0.0.1:5178，改代码自动刷新。
- `npm test`：单元测试；`npm run check`：单元测试 + 类型检查 + 构建；`npm run test:e2e`：浏览器端到端测试（需 Google Chrome）。
- 测试全部使用临时数据库和本地模拟的模型服务，不会调用真实 AI，也不会改动 `data/`。
- `npm run build:preview`：生成纯静态的演示版到 `dist-preview/`，数据存在访客浏览器，AI 不可用，只用于展示界面。
