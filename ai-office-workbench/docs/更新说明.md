## 0.1.0（2026-09-22）

本次在毕设交付版的基础上做了一轮界面与工程整理：新增主题切换揭幕动效与背景气泡特效，同时清理项目结构、重写文档。

### 新增

**主题切换揭幕动效**

- 点击右上角主题按钮时，新主题从屏幕底边向上「揭幕」占满全屏：浅色切深色时黑色自底部升起，深色切浅色时白色自底部升起。
- 揭幕边界是一条约 194px 的羽化过渡带，而不是一条硬邦邦的颜色分界线；上升过程约 620ms，中段匀速、收尾缓慢停住。
- 实现方式：View Transitions API 截取切换前后两张快照，只对「切换后」那张施加带羽化的渐变遮罩并自下而上推移遮罩位置（`src/lib/themeTransition.ts` + `src/style.css` 的 `::view-transition-new(root)`）。
- 不支持的浏览器（例如 Firefox）自动退化为瞬时切换；关闭动效开关或系统开启「减少动态效果」时同样瞬时切换，功能不受影响。
- 不点击主题按钮时页面表现与之前完全一致，没有任何常驻动画。

**背景气泡与场景轮播**

- 新增全屏气泡特效（`src/components/BubbleBackground/`）：Canvas 绘制缓慢上升的气泡，层级位于背景光晕之上、文字卡片之下，点击气泡会破开。
- 气泡的颜色随主题自动切换：监听 `<html>` 上的 `data-theme`，深浅两套配色；`data-motion="off"` 时暂停绘制。
- 渲染分辨率跟随设备像素比但不超过 2 倍，兼顾高分屏清晰度与低端设备性能。
- 登录页与工作台首页新增场景轮播（`src/components/SceneCarousel.tsx`），支持拖动切换、圆点定位、播放暂停；鼠标悬停、键盘聚焦、切到后台标签页或离开视口时都会暂停。
- 新增卡片边缘流光装饰（`src/components/LightFrame.tsx`），同样在离开视口或页面隐藏时停止动画。

**工程与文档**

- 忽略规则从 `*.log` 扩充为分组注释：`node_modules/`、`dist/`、`dist-preview/`、`data/`、`test-results/`、`.env` 与 `.env.local`、`.idea/`、`.vscode/`、`*.tsbuildinfo`、`*.log`、`.DS_Store`、`Thumbs.db`。`.prettierignore` 补上 `node_modules/`。
- README 重写，补齐目录树与文档索引；系统设计、交付说明、验收清单、安装使用同步更新，六份文档的索引互相一致。
- `docs/系统设计.md` 新增「界面动效」一节，说明四处动效的共同驱动方式与主题揭幕的完整流程。
- `docs/验收清单.md` 新增 A2「界面外观」小节（A13–A17），并把浏览器版本要求与 Chrome 依赖写入「已知限制」。
- `docs/安装与使用.md` 新增「界面外观」小节，常见问题补两条与动效相关的条目。

### 变更

- 主题切换的落地方式改为同步写入 DOM（`flushSync`），确保浏览器截取「切换后」快照时拿到的已经是新主题。
- 「夜间 / 白天」按钮的切换逻辑抽出为 `readTheme()` / `applyTheme()` 两个函数，`<html data-theme>` 作为全站唯一的主题来源。
- 动效开关（`data-motion`）现在同时控制气泡、场景轮播、卡片流光和主题揭幕四处动画，一处关闭全部停用。

### 修复

- 修正气泡特效在高分屏上的模糊问题（按设备像素比放大画布后再缩放绘制）。
- 修正主题揭幕过程中偶发出现颜色分界线的问题（由实心 `clip-path` 改为羽化遮罩）。
- 修正卡片角落闪光超出卡片边界的问题。

## 升级到新版本

适用于所有新版本，**数据不会丢失**：

1. 停止旧版服务（在运行 `npm start` 的终端按 Ctrl+C）。
2. 备份旧目录里的 `data` 文件夹；旧目录先不要删除。
3. 把新版解压到一个新目录。
4. 把备份的 `data` 文件夹复制到新目录里，与 `package.json` 同级。
5. 在新目录执行 `npm ci`、`npm run build`、`npm start`，用原账号登录。
6. 在「设置」页重新填写 API Key（Key 只存在进程内存里，重启即清空），API 地址与模型名称已保存在数据库中。
7. 确认记录、任务与操作日志都在以后再删除旧目录；有问题可以回到旧目录继续使用。

详细步骤见 [`安装与使用.md` 第 6 节](./安装与使用.md#6-升级到新版本保留数据)。
