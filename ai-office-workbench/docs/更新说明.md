# 更新说明

## 2026-09-19 毕设交付版

- 启动提示：Node.js 版本低于 24 时直接给出中文提示；端口被占用（例如旧版本还开着）时提示并退出，不再显示「已启动」；没有执行 `npm run build` 时提醒先构建。
- AI 输出：写作、知识库、AI 问答要求模型输出纯文本，减少 `#`、`**`、表格竖线等符号原样出现在结果里；会议摘要不再把未确定负责人的事项指派给发言人；项目拆解一般给出 5 到 12 条任务，避免模型堆满上限导致格式出错。
- 新增交付文档：`毕设交付说明.md`、`安装与使用.md`、`系统设计.md`、`演示案例.md`、`验收清单.md`，以及演示用文件 `案例资料/差旅费报销办法（示例）.txt`。README 与 API 说明补齐 AI 问答部分。
- 代码整理：统一格式，问答接口归入 AI 接口一组，功能和数据结构没有变化，旧数据可直接使用。

## 2026-09-19 问答及界面更新

- 新增独立 AI 问答：最多 20 轮连续追问，复制对话、导出 TXT、清空前确认，沿用设置中的模型配置。
- 背景改为相近冰蓝色渐变与缓慢动态柔光，支持日夜模式和关闭动效；修正功能卡片角落闪光超出边界。

## 从旧版本升级

1. 停止旧版服务，备份旧目录里的 `data` 文件夹，旧目录先保留。
2. 把新版解压到新目录，把 `data` 文件夹复制进去（与 `package.json` 同级）。
3. 在新目录执行 `npm ci`、`npm run build`、`npm start`，用原账号登录，在设置页重新填写 API Key。

详细说明见 `docs/安装与使用.md` 第 6 节。
