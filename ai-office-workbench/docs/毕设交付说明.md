# 毕设交付说明

AI 办公助手是一个在本机运行的个人办公工作台：写作、会议纪要、项目管理、文档分析、知识库和 AI 问答放在同一个界面里，数据保存在本机 SQLite，AI 功能通过 OpenAI 兼容接口连接你自己选择的模型服务。

## 1. 交付内容

| 内容 | 位置 |
| --- | --- |
| 后端源码（接口、账号、数据库、AI 调用） | `server/` |
| 前后端共用代码（类型、AI 结构校验、检索、日志） | `shared/` |
| 前端源码（页面、组件、样式、动效） | `src/`、`index.html`、`public/` |
| 自动化测试（26 组单元测试、5 组浏览器测试） | `tests/` |
| 依赖清单与锁文件、构建配置 | `package.json`、`package-lock.json`、`vite.config.ts`、`tsconfig.json` |
| 配置说明模板 | `.env.example`（端口与数据库位置）、`.env.preview`（演示版构建用） |
| 交付文档 | `docs/`（见第 6 节） |
| 演示用案例文件 | `docs/案例资料/差旅费报销办法（示例）.txt` |

不包含：`node_modules`（执行 `npm ci` 自动安装）、`dist/` 与 `dist-preview/`（执行 `npm run build` / `npm run build:preview` 生成）、`data`（首次启动自动创建）、`test-results/`（运行测试时生成），以及任何账号、数据库、API Key 和编辑器配置。目录里也不含 `.idea`、`.vscode` 等 IDE 工作区文件，这些已被忽略规则排除。

## 2. 运行环境

- Windows 10/11 或 macOS，Node.js 24 或更高版本（推荐 24 LTS）。
- 新版 Chrome、Edge 或 Safari。
- 第一次安装依赖需要联网；使用云端模型服务时需要能访问该服务。
- 不需要单独安装数据库或其他服务。

## 3. 启动与停止

```sh
npm ci          # 第一次或更新版本后执行
npm run build   # 第一次或修改前端代码后执行
npm start       # 启动，浏览器打开 http://127.0.0.1:4318
```

停止：在运行 `npm start` 的终端按 Ctrl+C。每次启动后需要在「设置」页重新填写 API Key。详细步骤、换端口、备份恢复、升级和常见问题见 `docs/安装与使用.md`。

## 4. 功能范围

- 单用户本机账号登录、个人资料、时钟与专注计时。
- 日夜主题切换（新主题自底部向上揭幕的过渡）、背景气泡与场景轮播、动效总开关。
- 写作、会议、项目（含任务看板）、文档、知识库五类记录的新增、修改、删除，真实保存在本机数据库。
- 六个 AI 入口：写作（撰写 / 润色 / 摘要）、会议摘要与待办、项目任务拆解、文档分析、基于知识库资料的问答（标注来源）、独立多轮问答。AI 结果先作为草稿，确认后才保存。
- 操作日志：记录每次增改删的前后内容，可回溯撤销。
- 演示版：`npm run build:preview` 生成纯静态页面，只展示界面，不调用 AI、不连接后端。

不在本次范围：多人协作、公网部署、支付会员、PDF / Word / 图片解析、录音转写、向量检索、问答历史永久保存。具体限制见 `docs/验收清单.md` 末尾。

AI 输出质量取决于所用模型。实测中较小的模型偶尔会补出原文没有的细节（例如电话、年份），所以所有 AI 结果都设计为可编辑的草稿，保存前请人工核对。
