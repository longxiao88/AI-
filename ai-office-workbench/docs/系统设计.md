# 系统设计

本文按当前源码说明系统结构，涉及的文件路径都可以在项目里直接找到。

## 1. 总体架构

```text
 浏览器（React 单页应用，src/）
   │  fetch /api/...（JSON，Cookie 会话）
   ▼
 Node.js 进程（server/，Express 5，只监听 127.0.0.1）
   ├─ 本机访问保护 → 登录校验 → 参数校验（Zod）
   ├─ 业务接口：记录 / 项目任务 / 知识库检索 / 操作日志 / 设置
   ├─ AI 接口 ──────────────► 模型服务（OpenAI 兼容 /chat/completions）
   │                            API Key 只在进程内存
   └─ SQLite（node:sqlite，data/workbench.sqlite）
 shared/：前后端共用的类型、AI 结构校验、知识库检索、日志差异计算
```

生产模式下前端先构建到 `dist/`，由同一个 Node 进程提供页面和接口，只需一个端口（默认 4318）。开发模式 `npm run dev` 同时启动后端和 Vite（5178），Vite 把 `/api` 转发到 4318。

## 2. 目录与模块关系

| 位置 | 职责 |
| --- | --- |
| server/index.ts | 启动入口：检查 Node 版本、打开数据库、监听端口、Ctrl+C 时关闭数据库 |
| server/app.ts | 全部 HTTP 接口、参数校验、AI 调用互斥、统一错误处理 |
| server/auth.ts | 单用户账号、登录、会话、登录失败锁定、个人资料 |
| server/db.ts | 建表、记录与任务读写、事务与操作日志、回溯、批量任务去重 |
| server/ai.ts | 调用模型接口、超时、服务商错误转换；写作 / 知识库 / 问答提示词 |
| server/office-prompts.ts | 会议 / 项目 / 文档三个模块的 JSON 输出提示词 |
| shared/ai-schemas.ts | AI 输入输出结构（Zod）与模型 JSON 解析 |
| shared/audit.ts | 快照差异、生成日志、回溯前的冲突检查 |
| shared/knowledge.ts | 知识库关键词检索与摘录 |
| shared/chat.ts | 问答请求结构：轮数、交替顺序、总字数 |
| src/App.tsx、src/config.ts | 页面框架、导航、未保存离开确认 |
| src/modules/*.tsx | 各功能页面，每个模块一个文件，互不引用 |
| src/lib/editor.tsx | 「列表 + 编辑表单」通用状态：切换、保存、删除、未保存提示 |
| src/lib/api.ts、preview.ts | 接口请求；演示模式下改用浏览器本地存储的模拟接口 |

写作、会议、项目、文档、知识库五个模块共用一套记录接口和 `useEditor`，差异只在各自的字段和 AI 操作。

## 3. 数据库

| 表 | 主要字段 | 说明 |
| --- | --- | --- |
| entries | id, kind, title, data(JSON), createdAt, updatedAt | 五类记录共用，kind 区分模块；各模块字段放在 data 里 |
| tasks | id, projectId, title, status | 项目任务，projectId 外键指向 entries，删除项目时级联删除；status 只能是 todo / doing / done |
| request_batches | requestId, projectId, titles, taskIds, createdAt | AI 批量加入任务的去重记录 |
| audit_logs | seq, id, payload(JSON) | 操作日志，payload 含动作、标题、每行的变更前后内容 |
| settings | baseUrl, model | 模型地址与名称（只有一行）；不存 API Key |
| account | username, passwordHash, salt, profile(JSON) | 唯一账号（只有一行） |
| sessions | tokenHash, expiresAt | 登录会话，只存令牌的 SHA-256 |

数据库开启外键和 WAL 模式。data 字段示例：写作 `{mode, input, output}`，会议 `{date, source, summary, todos}`，项目 `{description}`，文档 `{source, notes}`，知识库 `{source, keywords}`。

## 4. 保存与操作日志

所有写操作都经过 `store.audit()`（server/db.ts）：

1. `BEGIN IMMEDIATE` 开启事务，读取变更前快照（全部记录和任务）。
2. 执行写入，再读取变更后快照，用 `shared/audit.ts` 的 `difference()` 对比出增、改、删的行。
3. 有变化才写一条日志，然后提交；任何一步出错整体回滚，数据和日志不会不一致。

回溯时先检查日志涉及的每一行当前是否仍等于当时的「变更后」内容，被后续操作改过就返回 409，要求先回溯较新的操作；还会检查恢复后不出现没有项目的任务。回溯本身也记一条日志。

## 5. AI 请求流程

```text
页面点「生成」 → 前端禁用保存与重复点击 → POST /api/ai/...
  → 登录与参数校验（原文 ≤ 20,000 字，超出返回 400，不截断）
  → 互斥检查：已有 AI 请求在处理则 409
  → 组装 system 提示词 + 用户内容 → 模型服务（60 秒超时，不重试）
  → 写作 / 知识库 / 问答：直接返回文本
    会议 / 项目 / 文档：解析 JSON 并按结构校验，不符合返回 502
  → 前端显示为可编辑草稿（此时不写数据库）
用户编辑草稿 → 应用到表单 → 点「保存」→ PUT /api/entries/:id → 事务 + 操作日志
```

- 会议、项目、文档三个接口把用户内容以 JSON 字段发给模型，提示词声明其中的指令一律当作资料，降低提示词注入风险。模型返回允许外层包一层 ```json 代码块，其余格式一律按错误处理，不猜测修补。
- 项目拆解去掉完全重复的任务名；批量加入时前端生成 requestId，同一批重复提交返回上次结果（200），同号不同内容返回 409，已被回溯撤销的批次不会假装成功。
- 知识库问答先用关键词检索，最多取 5 条、每条 900 字摘录交给模型并要求标注来源编号；没有命中直接返回 404，不调用模型。
- 独立问答由前端带上整段对话（最多 39 条消息、总计 40,000 字、必须一问一答交替并以提问结尾），服务端不保存；客户端不能提交 system 角色。
- 写作、知识库、问答的提示词要求纯文本输出，因为结果显示在纯文本区域并可导出 TXT。

## 6. 认证与安全

- 账号：首次访问创建唯一账号，密码用 scrypt（随机盐）哈希保存。登录校验失败时也做一次哈希，避免从响应时间判断账号是否存在；同一来源连续失败 10 次锁定 15 分钟。
- 会话：登录后下发 32 字节随机令牌，Cookie 设置 HttpOnly、SameSite=Strict，有效期 7 天；数据库只存令牌的 SHA-256。退出时删除会话。
- 访问范围：服务只监听 127.0.0.1；`/api` 请求的 Host 必须是本机地址（防 DNS 重绑定）；写请求拒绝跨站 Origin 和 `Sec-Fetch-Site: cross-site`，并要求 JSON 内容类型。
- API Key：只存在服务进程内存的变量里，不进数据库、日志、浏览器存储，也不在接口返回（设置接口只返回 hasKey）；重启即清空。API 地址必须是 https（本机地址除外），不允许带账号、查询参数或片段；请求模型时禁止重定向。
- AI 处理中不允许修改设置和清除 Key，避免请求中途换连接。

## 7. 错误处理

| 情况 | 状态码 | 提示方式 |
| --- | --- | --- |
| 参数不合法、超长 | 400 | 「输入格式不正确，请检查必填内容及字数限制」 |
| 未登录 | 401 | 「请先登录工作空间」 |
| 非本机访问、跨站请求 | 403 | 拒绝 |
| 记录或任务不存在 | 404 | 「记录不存在或已删除」 |
| AI 请求重复、未配置模型或 Key、回溯冲突 | 409 | 具体原因 |
| 服务商返回 400/401/403/404/429 | 502 | 转换为通用中文提示，不透传服务商原始信息 |
| 模型返回空内容或 JSON 格式不符 | 502 | 提示手动重试 |
| 模型 60 秒未响应 | 504 | 提示超时、输入已保留 |
| 其他异常 | 500 | 「保存或处理失败，请重试」 |

前端失败时只显示提示，输入框、草稿和已保存内容保持原样，不自动重试，也不会用示例内容冒充 AI 结果。

## 8. 演示模式

`npm run build:preview` 使用 `VITE_PREVIEW_MODE=true` 构建。此时前端不访问后端，`src/lib/preview.ts` 用浏览器 localStorage 模拟记录、任务和操作日志接口，自带标注为「示例」的数据；所有 AI 和密钥接口直接返回不可用提示。它只用于展示界面，不代表真实的登录、保存或 AI 能力。
